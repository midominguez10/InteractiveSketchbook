Interface Audit - Micro Project

The page I am going to audit is my micro-project. From the interactive sketchbook and you press Micro-Project Final it will take you to the micro project. On top of the screen it says the title “Ride to School”. You can see that you are in the start of the game, as it says to “press space to start” so by that you know that the page is interactive. The only actions that are available is the space button which is shown in the beginning, and when you press space, the game starts and right after more of the instructions of the game pop up, saying “press SPACE bar when the green diamond lines up with the shape above.” This continues the game and then increases the speed of the diamond. If you get to the end of the game, it says that you lose or win whether you have time left in your timer. One thing that can be unclear is how much time is taken off whenever you choose the shape. There isn’t anything to navigate back to the start of the game again, so you have to manually restart the game even though when you finish the game to press space to start the game. Another thing you can’t do is go back to the main page of the interactive with a button or menu bar to go back, so you have to press back on the actual browser. The actual interaction has structure because the diamond starts in the middle, and there is a key and instructions that stay away from the actual gameplay. The interaction is pretty predictable. One thing that can be unpredictable is the actual speed of the diamond increasing after choosing the actual shapes, so that can catch users off guard, and there is also no indicator to show that the speed is increasing. One thing that the page assumes that the user understands is the time taken off when the shape is chosen, maybe a little indicator like a “-10 seconds” flashing on the screen is something that can help the users understand more about what is going on because the time is just taken off so the user just has to estimate how much time was actually taken off of the timer. One of the heuristics that the page violates is th Aesthetic and Minimalist Design because there is still clutter from the other submissions on the screen so moving that to another page to just keep the interaction would make this page much nicer., another thing is the instructions maybe after the first shape is chosen it can disappear to increase the imersion of the game and not make it feel like a tutorial the whole time. Another heuristic is the Visibility of System Status in the part where the shape is chosen like I said because adding a little flash of how much time was taken off would help the user a lot playing this game. Three main structural is the navigation of the page like the restart, also the state visibility by showing that part of the interaction they are in, for example putting level 2 when choosing the second shape, and the interaction clarity when choosing the shape adding how much time was taken off of the timer.
